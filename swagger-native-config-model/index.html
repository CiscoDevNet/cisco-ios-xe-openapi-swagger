🎯 Native Configuration API - Category-Based Organization

The native model is organized into 27 focused categories for optimal performance and discoverability. Select a category from the sidebar to explore API endpoints.

⭐ Top-Level Leafs: Simple values (hostname, version, config-register)

📦 Small Containers: Miscellaneous containers (vlan, logging, snmp, nat, spanning-tree)

🌐 IP/IPv6: Routing, ACLs, DHCP, DNS, NAT, neighbor discovery

📡 Router: OSPF, BGP, EIGRP, RIP, ISIS, MPLS, L2VPN/L3VPN

🔒 Crypto & Security: PKI, IPsec, IKEv2, TACACS, RADIUS, 802.1X, TrustSec

💻 Line & AAA: Console/VTY access, authentication, authorization

🔄 Switching & QoS: VLANs, bridge domains, MAC tables, VTP, QoS

🖥️ Platform & System: Boot, banners, memory, hardware modules

🔌 Protocols: BFD, NTP, CDP, LACP, UDLD, MVRP, PTP

📦 Other: 82 additional containers (call-home, archive, track, etc.)

🆕 Phase 2 (Feb 2026): App Services, L2 Discovery, Routing & Multicast, Security Services, Platform & Diagnostics, WAN & Legacy, Industrial & IoT, Misc Extensions

🆕 Phase 3 (Feb 2026): Policy Framework, Interfaces (Ethernet/Virtual/WAN/Service — 63 interface types), plus gap coverage for CEF, SLA, Device-Sensor, ETA, UTD, ND, Power
